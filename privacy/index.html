Политика конфиденциальности приложения «Радиочат»

Дата вступления в силу: 4 ноября 2026 г.

Настоящая политика описывает, какие данные обрабатывает мобильное приложение «Радиочат» (далее — Приложение) и как они используются. Приложение предназначено для обмена текстовыми сообщениями по радиоканалу через плату ESP32, к которой телефон подключается по Wi‑Fi.

1. Кратко

  • У приложения нет собственного сервера, аккаунтов, рекламы или аналитики.
  • Сообщения передаются между вашим устройством и платой ESP32 по локальной Wi‑Fi‑сети, а затем по открытому радиоканалу.
  • Android-версия использует сервисы RuStore для проверки обновлений и push-уведомлений. Для push SDK RuStore получает и использует push-токен; SDK также могут обрабатывать технические данные, необходимые для работы этих функций.

2. Какие данные обрабатываются

ДанныеГде хранятсяЗачем

Текст сообщений В памяти Приложения во время работы; последние сообщения — на плате ESP32 (история до 20 записей) Отображение чата и передача в эфир

Push-токен и технические данные для функций RuStore Передаются и обрабатываются SDK и сервисами RuStore на Android; состав и сроки обработки зависят от RuStore Доставка push-уведомлений и проверка обновлений

Приложение не запрашивает контакты, местоположение, фотографии, микрофон или файлы. SDK RuStore могут обрабатывать технические данные, необходимые для предоставляемых ими функций; подробности приведены в политике конфиденциальности RuStore.

3. Передача сообщений

Сообщения передаются в открытом виде по радиоканалу (звуковой AFSK‑сигнал через рацию) и по локальной Wi‑Fi‑сети между телефоном и платой ESP32. Радиоэфир по своей природе публичен: любой, кто настроен на ту же частоту и имеет совместимое оборудование, может принять сообщение. Не передавайте через Приложение конфиденциальную информацию.

Текст чата не отправляется серверам приложения: он передаётся по локальной Wi‑Fi‑сети на плату ESP32 (адрес 192.168.4.1), а затем по открытому радиоканалу. Отдельно Android-версия обращается к сервисам RuStore для проверки обновлений и работы push-уведомлений. SDK RuStore не предназначены для передачи сообщений чата.

4. Разрешения Android

РазрешениеНазначение
Интернет / состояние и изменение сети (INTERNET, ACCESS_NETWORK_STATE, CHANGE_NETWORK_STATE)Подключение к Wi‑Fi‑сети платы ESP32 и направление трафика Приложения именно в эту сеть, чтобы мобильный интернет можно было не выключать

Доступ к местоположению, камере, микрофону, контактам и хранилищу файлов Приложение не запрашивает.

5. Хранение и удаление данных

  • Имя в чате хранится на устройстве до тех пор, пока вы не измените его или не удалите Приложение (удаление Приложения стирает все его данные).
  • Сообщения в Приложении не сохраняются между запусками; при закрытии Приложения они удаляются из памяти.
  • История последних сообщений на плате ESP32 хранится в оперативной памяти платы и очищается при её выключении или перезагрузке. Плата находится под вашим физическим контролем.

6. Дети

Приложение не предназначено специально для детей. При использовании Android-версии технические данные для работы обновлений и push-уведомлений могут обрабатываться сервисами RuStore в соответствии с их политикой конфиденциальности.

7. Сторонние сервисы

Приложение не использует SDK аналитики, рекламы, отслеживания сбоев или авторизации. Android-версия использует SDK RuStore для проверки обновлений и получения push-уведомлений. При работе этих функций RuStore обрабатывает push-токен и необходимые технические данные. Приложение не отправляет текст чата собственному серверу или сервисам RuStore. Linux-версия не выполняет запросы к RuStore SDK. Передача сообщений выполняется через плату ESP32 в локальной сети и далее по радиоэфиру.
